Metagenome data processing and analysis

01: Adapter trimming
01_adapter_trimming.sh: Uses porechop to remove barcodes and adapters from the raw nanopore reads.

02: Metagenome assembly
02_assembly.sh: Uses Flye (--meta) to assemble the reads into contigs.

03: Read mapping to assemblies
03_mapping_to_assembly.sh: MiniMap2 maps reads onto assemblies. Samtools sorts and indexes .bam-files while also calculating mapping statistics.

04: MetaBAT2 binning:
04_metabat.sh: Runs MetaBAT2 on the Flye assemblies using contig coverage calculated from the read mappings. Although SemiBin2 was later selected as the primary binning method, the MetaBAT2 results were retained as an important baseline in the subsequent binner comparison.

05: GTDB-Tk classification
05_gtdbtk_classify.sh: Assigns taxonomy to the initial MetaBAT2 MAGs using GTDB-Tk.

06: CheckM2 genome-quality assesment
06_checkm2.sh: Runs CheckM2 on the initial MetaBAT2 bins to assess quality.

07: Sylph abundance profiling
07.1_run_sylph: Profiles trimmed nanopore reads against the GTDB r226 Sylph database.

07.2_make_sylph_sequence_abundance.sh: Converts the raw Sylph profiling output into sequence/genome-level abundance information suitable for downstream analysis.

07.3_collapse_sylph_abundance.py: Collapses and restructures the Sylph results into sample-level abundance summaries. This is used for plotting later on.

08: Assembly and binning strategy comparison
A major part of the workflow was evaluation of alternative approaches for recovering high-quality MAGs.

The comparison included:

standard Flye + MetaBAT2
Strainberry + MetaBAT2
Flye + SemiBin2
Strainberry + SemiBin2
Flye + MaxBin2
Strainberry + MaxBin2
DAS Tool refinement

MAG quality was compared primarily using CheckM2, while GTDB-Tk was used to evaluate taxonomy and recovery of Methylococcales.

08.1_strainberry_array.sh: Runs Strainberry on the original Flye assemblies.

08.2_metabat2_strainberry_array.sh: Runs MetaBAT2 on Strainberry-derived assemblies.

08.3_checkm2_strainberry.sh: Runs CheckM2 on MetaBAT2 Strainberry-derived bins.

08.4_gtdbtk_strainberry.sh: Assigns taxonomy to MetaBAT2 Strainberry-derived bins.

08.5_semibin2_array.sh: Bins both Flye- and Strainberry-derived assemblies in parallel using SemiBin2.

08.6_maxbin2_array.sh: Bins both Flye- and Strainberry-derived assemblies in parallel using MaxBin2.

08.7_prepare_binner_comparison_bins.sh: Collects and standardizes MAGs generated by the different assembly/binning combinations.

08.8_checkm2_binner_comparison.sh: Runs CheckM2 across all standardized binner-comparison MAG sets. This allows completeness and contamination to be compared directly across reconstruction strategies.

08.9_gtdbtk_binner_comparison.sh: Assigns taxonomy using GTDB-Tk on the standardized comparison MAGs.

08.10_summarize_binner_checkm2.py: Combines the CheckM2 results from the alternative assembly/binning strategies into standardized summary tables. The resulting dataset enables direct comparison of MAG number and quality between methods.

08.11_make_all_binner_combinations_tsv.py: Constructs a unified comparison table containing the evaluated assembly and binning combinations.

08.12_dastool_flye_array.sh: Runs DAS Tool using the alternative bin sets generated from the Flye assemblies.

08.13_prepare_dastool_bins.sh: Standardizes the DAS Tool output into the same structure used by the other binner-comparison datasets.

08.14_checkm2_dastool.sh: Runs CheckM2 on the DAS Tool-derived bins.

08.15_gtdbtk_dastool.sh: Assigns taxonomy to DAS Tool-derived MAGs using GTDB-Tk.

08.16_add_dastool_to_checkm2_comparison.py: Adds the DAS Tool results to the existing binner-comparison dataset.

At the end, the Flye-assembly-derived SemiBin2-bins were of the highest quality and the combination which managed to recover the most MAGs aswell. Hence these were chosen for downstream analysis.

09: Build the SemiBin2 MAG master table
09_build_semibin2_master_table.py: Builds a master table integrating all informatation about every bin so far.

10: Depth calculation 
10.1_semibin2_depth_array.sh: Calculates read-mapping depth information for the final SemiBin2 MAGs. Uses jgi_summarize_bam_contig_depths at 97% identity-threshold. This threshold were decided using the following script.

10.2_QC_barcode15_mapping_identity.sh: summarizes the empirical alignment-identity distribution and reports the number and fraction of alignments retained at several identity thresholds. Showed that 53% of primary alignments exceeded 97% identity. Also based on the fact that this was data from an enrichment where methylococcales may be closely related, 97% was chosen to able to tell these apart.

11: Calculate absolute MAG coverage
11_calculate_semibin2_MAG_coverage.py: Combines contig depth and bin membership to calculate coverage values for individual SemiBin2 MAGs. These coverage values provide an approximate measure of MAG abundance within each metagenomic sample.

12: ANI-based duplicate MAG assessment
12_check_semibin2_duplicate_MAG_ANI.sh: Uses pairwise genome similarity to investigate apparently duplicated or closely related Methylococcales MAGs. Distinguishes closely related strains and genuinely distict MAGs.

13: Bandage preparation
13_prepare_Methylococcales_Bandage.py: Prepares the recovered Methylococcales MAGs and their corresponding assembly information for visualization in Bandage.

14: Visualize SemiBin2 MAG coverage vs Sylph abundance
14_plot_semibin2_MAG_coverage_vs_Sylph.R: Plots mapping-derived MAG coverage with abundance estimated independently using Sylph.

15: Freeze final Methylococcales MAG set
15_freeze_semibin2_Methylococcales.py: Creates the definitive frozen set of Methylococcales MAGs used in downstream biological analyses

16: Prepare SemiBin2 functional-analysis inputs
16_prepare_semibin2_functional_inputs.py: Creates standardized input files and manifests required by FeGenie and the subsequent protein-level analyses.


Here starts there comparative genomics part, where the workflow is very similar to that of the globdb genome analysis.

17: FeGenie functional annotation
17_run_semibin2_fegenie_full.sbatch: Runs FeGenie on the final SemiBin2 MAG collection.

18: Functional screening of unbinned contigs
18.1_extract_semibin2_unbinned_contigs.py: Identifies assembly contigs that were not assigned to any SemiBin2 MAG.

18.2_run_unbinned_fegenie_full.sbatch: Runs FeGenie on the unbinned contig collection.

19: SignalP6 annotation
19_run_semibin2_signalp6_array.sbatch: Runs SignalP 6 on the final SemiBin2 MAG protein predictions.

20: FindMeHemes annotation
20_run_semibin2_findmehemes.sbatch: Runs FindMeHemes on the SemiBin2 MAG proteomes.

21: Finalize the SemiBin2 FeGenie run
21_finalize_semibin2_fegenie_run.py: Links FeGenie-generated protein files back to the authoritative SemiBin2 MAG manifest and constructs a stable protein-level dataset for downstream analyses.

22: Prepare DeepTMHMM candidates
22_prepare_semibin2_deeptmhmm_candidates.py: Combines the FeGenie, SignalP and FindMeHemes results and constructs the candidate protein population submitted to DeepTMHMM.

23: DeepTMHMM annotation
23_run_semibin2_deeptmhmm_array.sbatch: Runs DeepTMHMM on the selected SemiBin2 candidate proteins.
